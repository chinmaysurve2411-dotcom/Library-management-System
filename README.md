# Library-management-System
Library management system using C++


# Overview
I have built a console based Library management system using C++ which is a very powerfull programming language. 
As I am learning DSA (Data Structures and Algorithms) in C++ I have made this project as a implementation of the various concpets of DSA.


# some are:
- Vector (Dynamic Array)
- Linear Search
- Time compleity
- Deletion in Array/Vector
- Insertion
- Transversal
- Record Mapping (Book <-> Student)


# Features:

# Book Management 
- Add
- View
- Search
- Delete

# Borrow Management
- Issue books to students
- Return Books
- entry date
- return date

# Student Records
- student name
- Track book ID
- Borrow date
- Return Date
- Return Status
  
# Fine system 

- Borrow Period: 14 days
- Fine: 5/- per/day


# Menu options 
1. Add Book
2. View Books
3. Search Book
4. Issue Book
5. Return Book
6. View Borrow Records
7. Delete Book
8. Terms & Conditions
9. Exit
